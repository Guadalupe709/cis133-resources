# cis133-resources
A curated list of helpful reference resources for HTML and CSS.

## HTML Resource
* **[MDN Web Docs - HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)**
  * *Why:* MDN provides clear, accurate, and up-to-date documentation on every HTML element and standard, backed by practical code examples.

## CSS Resource
* **[CSS-Tricks](https://css-tricks.com/)**
  * *Why:* CSS-Tricks offers exceptional practical tutorials and visual guides (like Flexbox and Grid) that make complex layout design intuitive and easy to reference.
